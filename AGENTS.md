# Video work

- Run video rendering only on `ai@ml`. This includes full renders, previews, storyboard generation, and frame extraction. Never run these locally.
- Local work may edit source, run static checks, transfer files, and inspect downloaded artifacts.
- After rendering, verify the video and audio on `ml`, download the finished MP4 into the requested local video directory, and compare transfer checksums.
- Keep each song's supplied audio and lyrics unchanged. Do not overwrite existing outputs without permission.
- Obtain explicit written user authorization before edits, installs, commits, publishing, deletion, or other mutations. A request to implement or render authorizes work within that task, not unrelated changes.
